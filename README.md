# Contexto: AI-Powered Language Learning for Expats

Learning journey combining AI + L&D + Spanish education

## Lessons Completed
- Lesson 1: Market (La Cruz) - Shopping, haggling, groceries
- Lesson 2: Hospital - Medical appointments, insurance
- Lesson 3: Papelería - Stationery, printing, services
- Lesson 4: School - Uniforms, activities, admin

## Tech Stack
- RAG system (FAISS + HuggingFace embeddings)
- Groq LLM integration
- Location-aware Spanish learning

## Goal
Build AI-enabled language learning for real expat needs by April 2027
